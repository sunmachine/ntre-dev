About this prototype

What this is, how it is built, and what to critique

This is a static HTML prototype of a wiki for NEOTOKYO Rebuild (NT;RE). It exists to settle structure, page types and visual design before a real wiki engine is chosen.

Contents
  1. How the numbers are sourced
  2. Page types demonstrated
  3. Not in the prototype
  4. Build

How the numbers are sourced

Every stat on this site was extracted from the NeotokyoRebuild/neo repository: weapon scripts in game/neo/scripts/ and the C++ gameplay code in src/game/. Each number carries a footnote that links to the exact file and line it came from, pinned to a specific commit (see the page footer).

When the game changes, the data can be re-extracted and every page regenerated. A real wiki would do the same through a bot or data pages.

Page types demonstrated

  • Hub pages: Main page, Weapons, Classes, Game modes
  • Data-driven articles: every weapon page is generated from one record, with an infobox, stat breakdown and loadout table
  • Mechanic articles: hand-written explanations with citations, such as Thermoptic camouflage and Damage & penetration
  • Reference tables: Console variables, Maps, Loadouts & ranks

Not in the prototype

  • Search, editing, page history and talk pages (the tabs are visual placeholders)
  • Images: grey hatched boxes mark where screenshots or renders would go, pending a decision on asset licensing
  • Lore and story content: this pass covers gameplay mechanics and stats only

Build

Run python3 build.py in prototype/. Page bodies live in content/, extracted game data in data/, and the output is written to site/. No dependencies beyond the Python standard library.
