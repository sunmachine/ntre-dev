Maps

The official NT;RE map list

NT;RE ships with 32 official maps: 24 for Capture the Ghost, 3 for Juggernaut, 1 for Team Deathmatch, 2 tutorials and 2 menu backgrounds.

Prototype Each map would get its own page with an overhead layout, ghost spawns, capture zones and callouts. That needs the map files to be inspected, which this pass didn't do.

Other map files

The neoAssets repository (commit 467c146) has every official map plus two that aren't on the official list:

  • ntre_apparatus_dm: a Deathmatch map. It has its own soundscape file in the main repository.
  • devbox: a development test map.

The game also mounts original NEOTOKYO content, so the original nt_* maps may load. How they get their game mode hasn't been checked; a map without a game-config entity falls back to Free Roam.[2]
